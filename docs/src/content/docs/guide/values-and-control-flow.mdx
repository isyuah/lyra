Lyra 的代码主要由表达式组成。这一章先把最小的积木摆齐：怎么绑定值、有哪些基本类型、字符串和字节怎么表示、运算符怎么用，以及 `if`、`while`、`for` 这些控制流为什么也能产生值。

## 绑定：val 与 var

`val` 表示不可重新赋值的绑定，`var` 表示可以重新赋值。类型通常可以推断；需要明确时写 `: T`。

```lyra
fn main(): Unit {
    val name = "Ada"
    var visits = 0
    visits += 1

    val small: UInt8 = 0b1010_0101
    val big: UInt64 = 0xffff_ffff_ffff_ffff

    print(name)
    print(visits)
    print(small)
    print(big)
    print((-1).toUInt8Checked() ?? 3)
    print((255).toUInt8Checked() ?? 0)
}
```

```output
Ada
1
165
18446744073709551615
3
255
```

`val` 限制的是绑定本身，不是它指向的对象。`val user = User("Ada")` 不能再让 `user` 指向另一个 `User`，但如果 `User` 的字段声明为 `var`，仍然可以改对象内容。`struct` 和 `class` 的区别会在[数据建模](/guide/data-modeling/)一章展开。

数值字面量支持下划线分组、十六进制 `0x`、八进制 `0o` 和二进制 `0b`；浮点可以用 `1.25f32` 这样的后缀指定 `Float32`，不带后缀的浮点字面量默认是 `Float64`。

## 基本类型

| 类型 | 说明 |
|---|---|
| `Int8/16/32/64`、`UInt8/16/32/64` | 定宽有符号/无符号整数；`Int`、`UInt` 是 64 位别名 |
| `Float32`、`Float64`（`Float`） | IEEE 754 浮点数 |
| `Bool` | `true` / `false` |
| `Char` | 单个 Unicode 标量，单引号字面量 |
| `String` | 不可变 UTF-8 文本 |
| `Bytes` | 不可变原始字节串 |
| `Unit` | 没有有意义的值；`print(...)`、赋值等语句的结果 |

整数溢出和除零在 Debug、Release 都会报错，并带源码位置；不会静默回绕。窄化必须显式做，例如 `value.toInt8Checked()`、`value.toUInt8Checked()`，返回 `Option<T>`：越界时是 `None`。浮点转整数只接受没有小数部分且在目标范围内的值；`127.5` 是 `None`，不会截断。

```lyra
fn main(): Unit {
    print((127.0).toInt8Checked() ?? 0)
    print((127.5).toInt8Checked() ?? 0)
    val count: Int8 = 7
    print(count.abs())
    print((-3).clamp(0, 10))
}
```

```output
127
0
7
0
```

`abs`、`min`、`max`、`clamp` 是数值类型的内置方法；它们保持接收者的类型，不会偷偷把 `Int8` 提升成 `Int`。

## 字符串、字符与字节

`String` 是 UTF-8 文本，索引和 `size` 按 Unicode 标量计数，不按字节。需要字节长度时用 `byteSize`，需要原始字节时用 `toBytes()`。

```lyra
fn main(): Unit {
    val name = "Lyra"
    val text = "Hello, ${name}! \u{1F642}"
    print(text)
    print(text.size)
    print(text.byteSize)
    print(text[7])

    val raw = r#"C:\temp\new"#
    print(raw)

    val bytes = b"\xE4\xB8\xAD"
    print(bytes.size)
    print(bytes.toString() ?? "invalid")

    for ch in "é中🙂" { print(ch) }
    for byte in b"\x80\xFF" { print(byte) }
}
```

```output
Hello, Lyra! 🙂
14
17
L
C:\temp\new
3
中
é
中
🙂
128
255
```

几个容易混淆的点：

- `"..."` 是 `String`，`'...'` 是单个 `Char`，`b"..."` 是 `Bytes`。`b"\xFF"` 允许非 UTF-8 字节；普通字符串不允许。
- `r#"..."#` 是原始字符串，反斜杠不转义；`br#"..."#` 是原始字节串。分隔符可以加多个 `#` 来包含 `"#`。
- `Bytes.toString()` 返回 `Option<String>`；字节不是合法 UTF-8 时是 `None`，不会替换成问号。
- 字符串插值 `${...}` 调用值的显示形式；自定义类型可以提供 `fn toString(): String`。插值表达式按源码顺序求值。
- 字符串和字节都不可变；`bytes[0] = 42` 会报错。

## 运算符

常见运算符分成几组：

- 算术：`+`、`-`、`*`、`/`、`%`，以及 `+=`、`-=`、`*=`、`/=`、`%=`。
- 比较：`==`、`!=`、`<`、`<=`、`>`、`>=`。
- 逻辑：`&&`、`||`，短路求值；`!` 取反。
- 位运算：`&`、`|`、`^`、`~`，以及 `<<`、`>>` 和复合赋值。
- 范围：`0..<count` 不包含右端，`1..count` 包含右端。
- 空值：`?.` 只在接收者非空时访问成员，`??` 只在左侧为空时求右侧。

```lyra
fn main(): Unit {
    print(1 + 2 * 3)
    print((1 + 2) * 3)
    print(7 / 2)
    print(7 % 2)
    print(true && false || true)
    print(1 << 3)
    print(0b1100 & 0b1010)
    print(0b1100 | 0b0010)
}
```

```output
7
9
3
1
true
8
8
14
```

整数除法向零截断；除数为零会报错。移位量超出类型宽度也会报错，不会按 C 的未定义行为处理。混合位运算和比较时，建议直接加括号：`(flags & mask) != 0` 比依赖优先级更好读。

## 控制流也是表达式

`if` 在值位置必须有 `else`，两个分支产生共同类型。`while` 和 `for` 本身产生 `Unit`，但循环体里可以 `break`、`continue` 和 `return`。

```lyra
fn classify(value: Int): String {
    if value < 0 { "negative" }
    else if value == 0 { "zero" }
    else if value % 2 == 0 { "even" }
    else { "odd" }
}

fn main(): Unit {
    for value in [-3, 0, 7, 10] {
        print("${value}: ${classify(value)}")
    }

    var total = 0
    var index = 0
    while index < 10 {
        index += 1
        if index % 3 == 0 { continue }
        if index > 8 { break }
        total += index
    }
    print(total)

    for i in 0..<3 { print(i) }
    for i in 1..3 { print(i) }
}
```

```output
-3: negative
0: zero
7: odd
10: even
27
0
1
2
1
2
3
```

`for` 可以直接遍历列表、字符串和字节串，也可以遍历提供 `iterator()` / `next()` 的自定义集合；整数范围用 `..<` 或 `..`。`for` 的循环变量每次迭代都是新的绑定，闭包捕获它时不会共享同一个槽位。

块本身也是表达式。块正常结束时，末尾表达式的值就是块值；末尾加分号则丢弃结果，块值变成 `Unit`。

```lyra
fn main(): Unit {
    val message = {
        val base = "Lyra"
        "Hello, ${base}"
    }
    val score = if true { 60 } else { 0 }
    print(message)
    print(score)
}
```

```output
Hello, Lyra
60
```

这条规则有一个常见坑：`fn total(): Int { 1 + 2; }` 的块值是 `Unit`，不是 `Int`，编译器会在返回类型处报错。要么去掉分号，要么写 `return 1 + 2`。

## 练习

1. 用 `for` 和 `if` 写 FizzBuzz：3 的倍数打印 `Fizz`，5 的倍数打印 `Buzz`，同时是两者打印 `FizzBuzz`，其余打印数字。
2. 读一个十进制字符串并转成 `Int`。使用 `import std.text.{StringOps}` 和 `text.parseInt()`，分别处理 `Ok`、`Err` 和越界。
3. 把 `"é中🙂"` 的每个 `Char` 打印出来，再打印它的 `size` 和 `byteSize`，解释两个数字为什么不同。
