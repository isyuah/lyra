## 这套教程怎么用

教程按一条真实的工程路径推进：先写出可运行的小程序，再建立类型与错误模型，最后把同一套写法用到 JSONL CLI 和 HTTP/SQLite 服务上。每一章都有可复制的 Lyra 代码和预期输出；示例以当前仓库（0.1 Alpha）的实现为准。

## 版本边界

当前文档对应 Lyra `0.1.0-alpha.1` 的仓库工作树。语言和包格式仍在开发期；教程只讲解编译器已经实现、仓库测试或示例能够验证的行为。RFC 中“已接受但未实现”的设计不会写成可用 API。
