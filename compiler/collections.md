# 列表与调用绑定

```text
fn take<T>(first: T, rest: T...): List<T> { rest }
val ids = [2, 5]
val numbers = take(1, ...ids)       // List<Int>，有两个元素
val lists = take(ids, ids)          // List<List<Int>>，有一个元素
```

`List<T>` 是可变引用。`items.size` 读取个数，`items.add(value)` 在末尾追加，`items[index]` 读取或写入元素。空字面量需要元素类型，例如 `val ids: List<Int> = []`。下标从零开始；本阶段越界会定位到 `[` 并非零退出。

变长形参只能在最后。绑定器先区分固定槽、单个变长元素和 `...` 展开；显式表达式按源码顺序各求值一次，展开在该位置取得列表元素的快照。每次调用都有自己的变长列表。元素本身仍遵循原有语义：改 `values[0]` 不会改调用方槽位，但改它指向的 Class 则双方可见。直接传给固定的 `List<T>` 形参时始终共享列表。

只对缺省的形参执行默认表达式。它们在声明模块中按类型检查，能引用之前的形参；在实例方法中也能访问接收者。默认表达式按声明顺序在显式实参之后求值；调用异步函数时，默认值仍在创建冷 Task 之前求出。原生后端将默认值编成接收前面实参的内部函数，不在调用方重新解析或替换源码。

列表的目录和元素快照都由 GC 扫描。替换元素只替换目录中的引用；已展开的列表可继续使用原快照。下标赋值先确定列表和下标并检查边界，再求右侧；写入内联 Struct 的单个字段时，保留右侧对同一元素其他字段的修改。目录访问使用分片互斥，不让阻塞工作线程与执行域并发访问时损坏目录或读到撕裂的复合值。
